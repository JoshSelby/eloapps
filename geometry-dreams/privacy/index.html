Geometry Dreams Uploader Privacy Policy

Effective October 19, 2026

Geometry Dreams Uploader is a private tool used only by the owner of the Geometry Dreams YouTube channel (ELO Apps) to upload that channel's own videos. This policy explains what it accesses and what it does with it.

The short version

  • The tool is used by one person: the channel owner. It has no other users and no public sign-up.
  • It accesses only the Geometry Dreams channel, through Google's YouTube Data API, after the owner signs in and grants access.
  • It collects no data about viewers or anyone else, and it does not sell, share or transfer data.

What it accesses through YouTube API Services

Upload permission (youtube.upload): used to upload the channel's own videos with their title, description, tags, privacy setting and scheduled publish time.

Read-only channel access (youtube.readonly): used only to read the signed-in channel's ID and name, so the tool can confirm it is posting to Geometry Dreams and not another channel.

Where data is stored

The Google sign-in token is stored only on the channel owner's computer. Nothing is sent to any server other than Google's. The tool keeps a local list of the channel's own videos (titles, files and YouTube video IDs).

Revoking access

Access can be revoked at any time from the Google Account's security settings, under third-party access: myaccount.google.com/permissions.

Google and YouTube

This tool uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
